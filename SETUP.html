SBC Market Tracker

Phone setup

  1. Open this repository in GitHub.
  2. Go to Settings → Pages.
  3. Set Source to GitHub Actions.
  4. Go to Actions → Update SBC prices and deploy.
  5. Tap Run workflow.
  6. When it finishes, open the Pages address on your phone.
  7. In Chrome choose Add to Home screen or Install app.

Automatic updates

The included GitHub Action checks sources every 6 hours and republishes the site.

Add retailers

Edit scraper/sources.json. Each source defines retailer name, region, currency, URL and adapter.

Important

No single public feed contains every SBC listing. Coverage grows as sources are added. Always verify final price, shipping, stock and seller on the retailer page.
