SBC Market Tracker

Open the tracker

https://rainmanda1st.github.io/sbc-market-tracker/

In Chrome on Android, use Add to Home screen if you want it to behave like an app shortcut.

Automatic updates

The GitHub Action refreshes the credential-free retailer sources every 6 hours and republishes the site automatically. You do not need to run it manually unless you want an immediate refresh.

Manual refresh: open the repository, choose Actions → Update SBC prices and deploy → Run workflow.

Credential-free mode

The active tracker currently uses public retailer pages or feeds only. Active coverage is defined in scraper/sources.json.

Amazon.ca and AliExpress are already reserved there as disabled future integrations. They stay completely inactive until credential-based adapters are deliberately enabled later.

Add retailers later

Credential-free retailers can be added to scraper/sources.json with the shopify or generic adapter. The generic adapter can read JSON-LD and common server-rendered product cards.

Important

No single public feed contains every SBC listing. Coverage grows as sources are added. Always verify final price, shipping, stock and seller on the retailer page before purchasing.
